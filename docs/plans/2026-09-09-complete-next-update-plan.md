## 2. 自然创建、精确修改和真实完成

这是下一輪的首要产品修复。现有真实深度求索样例已出现空卡写模块→另建命名卡→清理重复模块；原 Agnes（模型）包尚待分析。前面四批已经完成定向软件验收，原来“最后再查”的 Agnes 反馈现在进入此组，不再无限顺延。

| 编号 | 要处理什么 | 实施与完成标准 |
|---|---|---|
| C1 | 原包逐轮诊断（待做） | 核对实际版本、模型、提示词、工具定义、用户原话、参数、回执和库中对象。逐项定位三张零散世界卡、重复整合、二十次未完操作及重复“我已经”；不提前定性为模型适配 |
| C2 | 空卡与正式建卡衔接（待修） | 普通创建由同一个明确目标完成命名、正文、模块和归库。隐藏占位供软件内部承接，不让模型为命名绕行重建。检查已有卡改名／简介／启动方式的标准编辑能力，普通编辑不强迫走高级变更协议 |
| C3 | 模块编辑语义（待修／补验） | 清楚区分新增、更新、追加正文、整理合并、排序、移除。修改沿用原模块编号；先读已有内容，保留无关部分，重试不重复。语义相似不自动删除，作者修订与真实冲突不被机械去重 |
| C4 | 合理分卡与多卡能力（待修／补验） | “把这份资料做成世界卡”默认完整组织为所需卡和模块；明确要求多张则创建多张。三张空卡从来不是上限，也不强制每个小设定一张卡。文游可以只有规则和共创开局，不强制先建世界及角色 |
| C5 | 外部文本转原生卡（补验） | 普通文本、外部结构化资料、混合章节均可先解读再进入原生工具；忠实保存与改写创作分开。能通读的记录实际覆盖，未解析部分明确，不因不支持一键导入而拒绝模型整理 |
| C8 | 外部世界卡、角色卡与文风资料直接导入（实施中） | 导入使用不以模型格式转换为前提。已支持格式本地解析；未知可读格式原文保留在用户所选卡类中，正常归库、编辑、引用和采用。保留未知字段和来源，不强迫细分模块；后续用户主动挂到管理工作区时才调用人工智能规范化。 |
| C6 | “创作模式”、模板与工具说明（待核验／修） | 快捷入口不伪装成另一套受限模式，不把明确创建请求改成多轮规划问答。查清“文游只有两个模板”是页面、启动方式还是模型误解；复验四种既有启动方式，不能把模板数量当创建能力限制 |
| C7 | 失败与完成（待修／补验） | 已写入但回读失败明确保留原对象；无新信息的失败不无限重试、不换工具绕权限、不重建整卡。完成必须有可见成果和正确打开入口；代码、工具教学和回执使用同一事实，不依赖固定动词匹配 |

前端：回答成果入口、三类库与同一张卡详情同步；修改模块后回到原模块。工具完整参数留执行详情，正式答复只说明实际成果、必要冲突和剩余问题。禁止用过滤关键词或删除日志伪装输出质量改善。

## 直接导入外部世界卡、角色卡与文风资料（C8）

1. 用户在世界库或角色库的导入入口选择文件，软件本地读取。原生包继续严格校验；已明确支持的外部格式按现有规则转换，不必发给模型。损坏的原生压缩包不能通过原文回退伪装成完整导入。
2. 对未知但可解码的 JSON（结构化数据）、Markdown（标记文本）或普通文本，预览“按原文导入”，一次保存所选类型的卡片和原文模块。内容放入普通文本字段，不把外部键名当作本软件字段解释；格式不合法的结构化文本也可作为原文保存。原始文件保留在本卡目录内，不在库里多冒出一个陌生作品。
3. 用户可直接打开模块编辑原文。卡片本身拥有正常稳定编号、归库、复制、引用和导出行为；不能采用只保留交换数据、却被上下文加载跳过的“不支持模块”形式。
4. 选择该卡作背景后，可按原文直接采用，无需先规范化；导入本身不启用背景、不切身份。用户要求的整块原文采用必须在预算允许时完整进入实际请求并有来源记录，不走关键词抽样后宣称全量采用。超出当前有效窗口时明确说明未完整采用，提供调整范围／按需读取／整理选项，不静默截断或强行发送。原文里的外部宏、脚本、图片链接及触发配置作为文字存在，不承诺执行其平台效果，也不取得工具权限。
5. 后续在该卡“让人工智能整理”中，用户可要求拆模块、提取世界条目、整理章节；调用现有三档权限和标准卡片编辑流程。默认整理同一张卡，保持稳定编号和引用；原文保留为来源／历史，规范化后的有效模块替代旧原文的活动采用，不能原文与新模块同时重复注入。正在游玩的旧快照仍须明确刷新。
6. 用户纠正的重点是取消使用前的强制模型转换费用。直接导入后即可使用，是否整理完全可选；整理沿同一张卡及现有管理权限执行，不把上下文用量解释当作导入需求的替代。角色原文在选择该角色回答时可读，文风资料作为已采用的设定可读。
7. 验收：未知对象、数组、非标准结构化文本、中文长文件、编码失败、同名文件、原文编辑、退出重开、实际采用、导出、后续整理不换卡／不重复采用。二进制、加密或无法提取文字的文件明确不能伪装成可读设定。
