# Novex 八页面与版本面板复刻规范

本文把 2026-09-02 用户确认的三张参考图转换为可测量的 Android Compose 实现规范。参考图是构图合同；其中已经明确指出的生成偏差不进入产品。本轮直接复刻会话列表、世界目录、角色目录、世界展示、世界编辑、世界预览、角色展示、角色编辑八个页面，以及角色版本选择底部面板。

参考图包含手机外壳和演示素材，产品只复刻应用内容区。首要截图基线使用 412×915 dp 的竖屏视口；360 dp 宽度用于窄屏回流验收，字体放大 1.3 倍用于可读性验收。

## 固定视觉参数

| 参数 | 目标值 |
|---|---:|
| 页面水平边距 | 16 dp |
| 顶部栏内容高度 | 56 dp |
| 底部安全操作区 | 72 dp + 系统导航安全区 |
| 主标题 | 24 sp / 700 |
| 页面标题 | 20 sp / 650 |
| 列表标题 | 16 sp / 600 |
| 正文 | 14 sp / 400，行高 21 sp |
| 次要文字 | 12 sp / 400，行高 17 sp |
| 常规图标 | 20–22 dp |
| 最小触摸目标 | 48×48 dp |
| 卡片圆角 | 8–12 dp；媒体卡以 8 dp 为主 |
| 分隔线 | 1 dp，低对比度 |
| 常规描边 | 1.7 dp，圆头圆角 |

浅色基线：页面背景 `#FBFBFC`，主文字 `#17181C`，次要文字 `#686B73`，分隔线 `#E7E8EC`，主色 `#315F9F`，主色浅背景 `#EEF3FA`。图片之上的文字使用底部黑色渐变遮罩，避免为每张图片写死颜色。

不使用默认 Material 3 卡片阴影和胶囊堆叠。层级主要依靠媒体、留白、文字重量与分隔线建立。深色方案本检查点保留现有主题兼容，但不以未提供的深色参考图声称视觉等同。

## 图标资源规则

- 主图标来源为 Phosphor Icons，固定到仓库中记录的版本和许可文本。
- 默认使用 Regular 线性图标；选中态可使用 Fill 或 Duotone，但同一控件的轮廓不得跳动。
- 只收录页面实际使用的 SVG，并转换为本地 VectorDrawable 或 ImageVector；运行时不联网取图标。
- 搜索、更多、添加、返回、编辑、预览、拖动、人物、世界、对话、闪光等核心图标必须来自同一体系。
- 若第三方图标缺少世界专属语义，自绘图标必须复用 24×24 网格、1.7 dp 描边、圆头和圆角。

## 顶层结构

四个根页面共享一个稳定容器：会话、世界、角色、文游。具体项目、编辑器、预览和模块详情是子页面，隐藏根导航。

### 聚合圆点导航

- 四个目的地顺序始终是“会话、世界、角色、文游”；当前空间在自己的顺序位置原地伸展为文字，其余为 8 dp 实心圆，不把当前文字统一挪到左侧。
- 收起时三项彼此靠近。可点击区域满足 48×48 dp，但没有可见胶囊、底座、背景条或选中底色。
- 导航固定在根页面底部安全区，不是列表末尾内容；根页面列表为它预留底部内边距，长列表滚动时导航不会被带走。
- 点击任意项后进入展开态，四个目的地都显示文字；切换目的地不会立刻收起，点击导航外部才恢复聚合状态。
- 点击圆点或水平切换时，目标圆点在原顺序位置伸展为文字，原活动项同时收缩回圆点；动画不改变“会话、世界、角色、文游”的阅读顺序。
- 点击导航本身切换后保持当前展开程度；点击导航外部收起。
- 按住导航可连续拖动选择，松手后切换并回到收起态；整个根页面的明确水平滑动也可切换相邻空间。
- 拖动和滑动不是唯一入口，每个目的地都具有可点击和无障碍语义。
- 使用平台触摸阈值锁定横纵方向，不写死像素距离；页面内横向媒体和系统边缘返回手势优先于根页面切换。
- 世界、角色或文游详情页不显示根导航，系统返回恢复原列表的滚动位置。

## 会话首页

页面主体是最近对话，不再显示“我的世界”概览卡。

- 顶部：标题 Novex、搜索和右上“帮我创作”入口；设置及创建／导入保留明确可达路径，但不能挤掉标题、搜索或底部新建对话。
- 筛选：最近、通用、创作；创作当前显示真实占位状态。
- 分组：今天、更早；行内显示封面或头像、标题、世界名、具体角色版本和时间。
- 底部“新建对话”只负责新建对话；顶部添加入口负责创建或导入世界、角色等内容。
- 搜索、批量选择和既有分组功能继续保留，但折叠为次级状态，不能挤压默认首页构图。

## 世界库

- 顶部：标题“世界”、搜索入口；搜索激活后在标题下方出现 40 dp 高搜索框。
- 世界卡以横向媒体为主，目标宽高比约 2.2:1；名称、简介、角色／场景／章节数量叠放在图片底部。
- 没有用户封面时使用稳定的淡色世界视觉指纹，不显示破图或强迫上传。
- 内容少时保留一个明确的新建入口；内容多时连续纵向排列，不嵌套额外白卡片。

## 角色库

- 顶部：标题“角色”、搜索入口。
- 每行展示 88×104 dp 的纵向头像／代表图、名称、两行简介和“本体 · N 个分身”。
- 分身数量只作为轻量信息，不在角色库直接铺开版本列表。
- 没有头像时使用稳定的淡色抽象人物轮廓，不生成虚构人脸。

## 世界展示页

- 顶部栏：返回、居中世界名、右上“帮我创作”和编辑；不放根导航。
- 顶部媒体宽高比约 2.05:1；没有图片时使用世界视觉指纹。
- 世界观概述默认存在；空概述仅显示一个克制的添加引导。
- 已添加模块按用户排序直接渲染实际内容预览：地图图片、时间线节点、势力图块、地区、事件等。
- 角色版本以横向头像列表呈现；开始对话保持单一明确的底部操作。

## 世界编辑与草稿预览

- 编辑页使用高密度但清晰的单列结构，不模拟展示页。
- 名称、概述和基础媒体固定在内容模块之前，不参与模块排序。
- 内置内容模块每种最多一个；自定义模块不限数量。
- 模块默认折叠，点击标题展开编辑；允许多个模块同时展开。
- 每个模块提供拖动手柄，并在更多菜单中提供上移、下移和删除。
- 右上眼睛进入草稿预览；预览使用尚未保存的数据和当前排序。
- 草稿预览复用世界展示渲染器，仅增加返回编辑的顶部栏，不重复实现另一套布局。
- 保存成功前不显示已保存；预览返回编辑时保留展开状态、滚动位置和输入光标。

## 角色展示、版本与编辑

- 角色展示与世界展示采用同一层级语言：顶部媒体、名称、简介、内容模块、关联世界。
- “帮我创作”固定在右上角，不进入人物内容区；本轮只保留诚实占位，不启动人工智能管理能力。
- “本体 · N 个分身”是名称下方的轻量入口；点击后打开底部版本选择面板。
- 从世界进入角色时直接展示该世界关联的具体版本；从角色库进入默认本体。
- 编辑页明确显示“正在编辑：本体／分身”，基础资料与媒体固定在前，内容模块按相同编辑器展开和排序。
- 角色草稿预览与正式展示共用渲染器，并隐藏所有空字段。

## 数据与状态边界

- 顶层切换只改变本地显示状态，不触发模型、工具或外部副作用。
- 展示页读取持久化对象；预览页读取编辑草稿；保存是两者之间唯一的数据提交边界。
- 根页面返回后恢复筛选、滚动位置和导航展开状态。
- 编辑器在软键盘、系统返回和进程前后台切换时保留草稿；系统返回先关闭键盘，再处理未保存草稿。

## 共享实现边界

- 世界与角色只使用一个内容编辑模块，统一草稿、多个媒体槽、字段分组、折叠、模块增删改名、排序、预览、保存和返回。世界与角色通过各自适配器提供字段、媒体语义、可添加模块和领域命令，编辑模块内部不得按领域写大段条件分支。
- 世界展示、世界草稿预览和角色展示使用同一个内容渲染入口。展示传入已保存文档，预览传入当前草稿；顶部栏和返回栈由页面外壳负责，内容渲染入口不接收“展示／预览”模式参数。
- 地图、时间线、集合、文章等结构拥有各自模块实现；相同形态通过参数化实现复用，不为地区、势力等复制只有名称和配色不同的薄包装。
- 世界媒体槽至少区分封面、标志、全屏背景；角色版本媒体槽至少区分头像、主页背景；地图和模块图片保持自己的语义。全部允许为空。
- 世界观概述是创建世界时默认存在的内置模块。其他世界模块由用户添加；自定义模块允许多个。未知模块必须原样保留。

## 分阶段复刻计划

1. **视觉基础**：颜色、排版、图标资源、顶部栏、媒体卡、空图指纹、聚合圆点导航。
2. **三根页面**：会话首页筛选与列表、世界库、角色库，完成点击与水平切换。
3. **世界展示**：媒体、概述、实际模块预览、角色版本和单一对话入口。
4. **世界编辑预览**：折叠编辑、模块唯一性、排序、草稿预览和保存状态。
5. **角色展示**：轻量版本入口、具体版本内容、关联世界和媒体展示。
6. **角色编辑预览**：共享编辑器、草稿预览、版本影响范围与可选图片。
7. **视觉校正**：在 412×915 dp 参考视口完成至少两轮截图叠加修正。
8. **设备验收**：窄屏、大字体、长文本、图片密集、软键盘、系统返回、恢复与真实设备滚动。

## 已知复刻风险

- 参考图由生成工具绘制，部分字体宽度、图标风格和手机比例内部不一致；以本规范固化后的统一数值为准。
- 参考图的人物和世界图片不是项目可分发资产；测试截图使用本地占位素材，正式显示使用用户资源或稳定视觉指纹。
- 不把 412×915 dp 的逐像素匹配机械拉伸到所有设备；目标视口保证高接近度，其他尺寸保证层级和交互一致。
