# 卡片页面链与参考图比例修正

## 失败基线与范围

用户提供开发候选四的五张手机截图：首层预览不能返回库、旧新建角色入口打开第二个库、展示组件跳过整卡编辑页、横向模块重复成竖向条目、简介混入页签、主图区和行距偏大。B75 继续开启，开发候选四界面验收失败。此前“没有同时保留两套入口”的记录不准确，已由本轮实际调用链纠正。

本轮只改卡片的页面接入、展示与编辑组合。不改内容存储、模型采用、权限、导出格式和稳定工作树；实际手机验收由用户进行。采用手机交互技能与界面还原技能的比例核对方法，不重新生成一套设计。

## 唯一页面链

库 → 已保存预览 → 点击内容组件 → 整卡编辑 → 模块编辑 → 整卡编辑。

- 整卡编辑的眼睛按钮打开草稿预览，返回保留编辑位置和草稿，不提交。
- 模块编辑返回整卡编辑，正文仍属于草稿，不询问整卡保存。
- 整卡编辑退出：按真实内容差异判断；无修改直接回已保存预览，有修改询问保存／不保存／取消。
- 已保存预览返回原来的库。库的搜索词、列表滚动和所选分类由原页面保留。
- 世界中的角色先返回所属世界；从角色自己的入口进入时返回原入口。
- 键盘打开时，先收起键盘，不丢弃草稿。

## 代码原因与修正

1. 原根页面把库与卡片详情嵌在同一局部选中状态中，旧页面地址又能创建另一套库。改为原库调用应用导航打开独立卡片页面，退出由同一导航退栈；旧无编号的新建入口直接进入创建流程，取消或完成后退出回原入口，不再展示另一个库。
2. 展示模块、图片、姓名、简介原来分别直达模块编辑、图片管理或弹窗。现在统一先进入整卡编辑；模块点击只定位对应页签及祖先展开状态。
3. 正式预览的返回原来会因读取刷新忙碌而被禁止。现在正式预览返回不受读取状态阻拦；编辑写入期间仍避免重复动作。旧手机上卡住的完整触发过程未复现，不将结构修正冒充实际复现。
4. 横向标题下不再重复同名模块行。自身有正文时只显示正文摘要，子模块才显示名称和摘要行。空正文不再渲染空摘要撑高条目。
5. 保留现有简介模块数据，仅让顶层独立简介在主图基本信息区呈现，不重复进入横向页签。有子模块或角色的同名模块仍留在正文树中，不吞掉其结构。已保存预览和草稿预览中的简介由同一个惰性正文列表完整读取，包括图片及长文本分段；编辑总览才使用单行摘要，不能以摘要代替正文。
6. 横向选中标题再次点击直接进入该模块编辑；竖向条目右侧使用进入箭头。排序及嵌套保留拖动，并可从模块编辑的“排列与嵌套”操作进入菜单。

## 验证边界

本轮按代码逐条复查页面回退、选中状态、草稿提交、已有内容保留及原版组件调用。编译和包签名证据放在本地忽略目录 `local/qa/card-navigation-20260911/`。本轮不代替用户进行手机点击验收，不声称渲染截图或拖动手感已经通过。

## 用户验收顺序

1. 在原角色库打开“士兵”，点左上角返回：应回到刚才的同一个库；系统返回同样如此。
2. 在原库点击新建：应直接创建，不能再出现第二个角色库。
3. 打开士兵，分别点击主图、姓名、简介：先到“编辑角色”，不得直接进入图片列表或模块正文。
4. 点模块进入正文，修改后返回：应回“编辑角色”，不询问整卡保存。
5. 点眼睛看草稿，再返回：应留在编辑，刚才文字和位置保留。
6. 从编辑返回首层预览：有修改才询问。先选取消应留在编辑，再选不保存应回旧内容；另做一次保存，应显示新内容。
7. 仅进入编辑看一眼再返回：不弹保存询问。
8. 世界重复同一条链；检查主图比例、页签下重复条目是否消失，以及内部角色返回所属世界。
