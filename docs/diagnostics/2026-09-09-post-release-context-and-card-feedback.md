- 分类：`NovexLibraryPicker`（资料选择器）支持创作库和文件夹，但与角色类型选择并列。用户在角色列表中找不到分类具有代码依据，不应再建分类系统。
- 工程层面判断：兼容规则仍在多个读取／显示入口重新推断状态；保留外部原文时未同步验证安卓大行读取；已有能力被不同入口分割。既有测试证明特定路径，不能外推为所有组合及真实文件规模已可用。后续验收应围绕“导入→归库→分类选择→指定用途→实际请求→保存重开→导出”贯通，身份、显示、背景、管理仍须分别保持用户明确选择。
