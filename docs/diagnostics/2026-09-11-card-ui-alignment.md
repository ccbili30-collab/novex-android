## 实施边界

卡片页面源码由独立 card-ui（卡片界面）构建模块移入原应用，包名保留 novex.android。应用直接调用同一套 NovexPageTopBar（页面顶部栏）、Novex 列表行、按钮、弹窗、输入框、选择控件、图标与设计参数；内容核心与存储仍是独立模块。没有复制整套原组件库，也没有换回旧卡片控制器。

主图在所有模块上方；编辑总览只给图片和基本字段组加边框。横向文字页签下方只有当前模块的内容；子模块以紧凑条目及层级线呈现。单模块采用名称横线与连续正文。图片选择展示资源缩略图；世界内部角色仍是独立内容对象。

简介复用名称为“简介／人物简介／世界简介”的普通模块，不额外复制正文。没有简介时，只在用户填写并应用后创建简介模块，取消或只打开查看不改变卡片。名称、图片、内容展示位置均调用共同编辑入口。

## 本轮检查范围（十类）

| 类别 | 必须同时看见的界面与行为 |
| --- | --- |
| 1. 创作库与进入 | 原版顶部栏、搜索、新建、导入；进入真实对象；加载失败不显示其他卡 |
| 2. 保存后的展示 | 世界／角色及有内容／空内容；主图、名称和简介位置；横向文字页签；长正文；点击部件进入编辑 |
| 3. 编辑总览 | 图片和字段组边框；当前页签下的紧凑模块行；细小新增行；只有操作状态突出拖动目标 |
| 4. 单模块编辑 | 名称横线、正文、图片入口、携带设置；预览按钮；软键盘不压住编辑区；正文和光标保留 |
| 5. 图片支线 | 缩略图网格、添加、头像／封面／模块用途；显示位置与资源本体删除区分；取消文件选择无修改 |
| 6. 世界内部角色 | 新建、从角色库复制、进入编辑；角色缩略图；移动展示位置不改变归属；移除需明确范围 |
| 7. 嵌套与排序 | 横向及竖向同级排序；拖入目标成为首个子模块；保留整组；不成环；菜单等效操作；切换页签仍能定位 |
| 8. 草稿／预览／退出 | 正式和草稿共用呈现；预览不保存；有实际修改才询问；失败保留输入；返回恢复目标和位置 |
| 9. 组件与小屏表现 | 原版字体、颜色、线条、图标、按钮、弹窗、选择器；触控目标；标题居中；安全区和键盘返回顺序 |
| 10. 对话采用与管理入口 | 对应设置也使用原版控件；互动、背景、管理保持分离；未改变权限及执行协议 |

## 代码级证据与实际边界

直接检查源代码和确认图：删除固定 260 单位宽度的根模块面板；不再使用通用材料设计顶部栏与文字冒充图标；原版控件为真实依赖，不只是主题颜色相同。

代码检查包括页面组合、每项点击的目标、草稿保存、父子层级、资源归属、返回和位置恢复。编译检查记录于本地忽略目录 `local/qa/card-ui-alignment-20260911/`。手机字体最终观感、布局实测、键盘及拖动手感仍须实际运行验收，不能由本文件宣称通过。

开始前快照：`before-ui.tar.gz`。首轮集成编译通过（5 分 56 秒）；编译期间的独立代码复查又检查到：

- 原版弹窗自带滚动，将旧页面的内层无界滚动一并带入会出现测量冲突。已在本地改为由弹窗统一管理；有界角色列表明确自管滚动。
- 自动显示选中页签如果使用通用“滚入可见区域”，会连带滚动纵向页面。已改成只调整横向滚动位置。
- 进入另一张内部角色卡时，列表状态必须按卡片编号隔离；返回当前模块时同步定位祖先页签并保留展开状态。
- 拖动中的浮动预览与实际树分离，不注册第二套拖放目标；实际移动仍完整保留子树。
- 普通正文渲染接回原应用已有的 MarkdownBlock（标记文本块），避免引入第二套正文排版规则。

这些改动已进入第二轮完整编译，尚未交付安装包。
