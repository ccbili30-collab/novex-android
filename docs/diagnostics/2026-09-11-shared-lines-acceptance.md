# 候选十：手机验收步骤

本轮不公开发布。候选使用预览应用包名及签名，保留原卡、对话和稳定版本。安装前无需卸载旧预览版。

## 1. 首页

打开应用 → 会话。应看到一个清楚的新建入口，点击直接打开空对话；不再出现重复的“从世界开始／帮我创作”以及最近／通用／设定三项分类。

## 2. 大世界开始互动

在世界库打开之前导入的大卡 → 开始互动 → 确认模型支持工具、当前权限自由 → 发“先读取这个世界的必要资料，再介绍开场，不要整理或改写原卡”。

期望：不会因自动选中一个超大正文块就阻止整个请求；资料未带全时模型能调用分段读取。过程显示正在读取什么，正常剧情保留在正文。模型实际回复内容需人工判断，本地合成检查不能替代此项。

## 3. 采用与管理同时存在

在同一对话选择这张世界卡作为管理对象 → 发“保留原文，只新建一个测试模块，写入港口有一座灯塔” → 完成后点成果或回世界库打开原卡。

期望：主要互动对象保留；新增模块在同一张原卡，保存成功才报告完成。连续再发一条请求应正常开始。之后可删除测试模块。

## 4. 卡片用于已有对话

打开一张角色或世界 → 更多 → 用于已有对话 → 选一个已有测试对话 → 选背景 → 保存并打开。

期望：不新建对话、不复制卡片、不擅自替换回答身份。再从卡片选择管理用途，应只增加管理范围。选择互动用途才替换主要互动对象。

## 5. 上下文容量

进入模型选择并刷新模型列表，再打开对话的上下文容量设置。切换相关模型分别查看最大值。明确第四代型号与无明确型号的中转别名须分别记录；估算会有提示。若仍为错误值，请保留该模型完整标识与模型列表响应中的容量字段，不需要密钥。

期望：界面与实际请求使用同一容量来源；具体中转服务能否提供百万容量，以真实返回和调用为准。

## 6. 正文和过程

发“先写一段港口剧情，然后读取世界的设定，再接着写人物对白”。结束后展开工作记录，再收起；退出对话重新打开。

期望：前后剧情及对白仍能读到，收起的是工具等过程，不是整段正常正文；每项操作可查看真实结果和失败信息。

## 7. 共用支线

将一张测试图片发到对话，让模型保存到指定卡并读取图片。核对图片归卡后确实可打开；如果视觉服务不可用，应明确失败。再注册一个查看快捷操作和一个行动快捷操作：查看不发送剧情行动，行动只发一次。

保存一个测试存档并打开详情，核对名称、状态和原始消息。此候选不以“保存成功”代替“选档恢复成功”；指定恢复范围仍待确认。
