# 卡片核心接回原应用：代码语义复查

本轮交付对象是原应用的预览渠道私有体验候选，不是独立演示应用，不公开发布。稳定工作树不动。实现位置：`worktrees/tasks/card-core-integration`；旧修复工作树与独立实现均保留。

## 本轮边界

- 保留原应用入口、原对话与消息、模型服务配置、工具权限和执行记录、通用附件与语音等能力。
- 新内容核心以库接入；不采用独立实现的应用入口、独立对话存储或独立模型连接页面。
- 世界与角色共同使用新内容存储、模块与图文编辑、预览、保存和原生交换包。
- 新建对话默认使用新卡片关联。已有对话保留历史设定；用户可从“采用新版卡片”显式改用新资料，避免猜测旧分身、阶段及历史快照应如何合并。
- 旧卡读取后生成独立新副本，保留原表。世界内角色复制独立；旧文游的资料保留为世界副本。角色不同版本分别保留。映射属于兼容保全，不宣称旧分身与阶段已获得新产品语义。
- 旧卡主要详情和编辑入口转向新副本；不再向模型提供旧卡写入接口，防止页面与工具各写一份。

## 已进行的语义复查与改动

| 环节 | 代码行为与判断 |
| --- | --- |
| 手工编辑 | 卡片页读取新正式内容；模块编辑产生持久草稿，预览读取同一草稿，保存才替换正式修订。 |
| 原对话连接 | 卡片按钮携带持久的短入口编号进入原新建对话流程，沿用模型、分组与记忆默认设置；创建原会话时保存卡片关联及名称。 |
| 关联保存 | 卡片采用与管理纳入原对话配置的统一保存流程，随设置与存档保留；不是另一份本地偏好中的主状态。 |
| 模块携带 | 默认未配置模块交由模型选择；必带、条件及对话内停用由软件计算。一次请求复用选料结果，工具多轮不反复调用选择器。 |
| 容量 | 原卡内容与模型预算分离。选料或正式材料超过可用预算时明确阻止发送，不把截断模块视为完整采用。 |
| AI 编辑 | 原工具循环执行新卡片工具；采用只给读取权限，管理才可修改。读取最新版本后调用共同编辑保存能力。 |
| 权限与停止 | 继续使用原只读、批准、自由机制；外层批准后不重复批准。停止信号接到内容写入的停止检查。 |
| 完成与成果 | 只有实际保存回执才生成成果入口；部分失败单独显示。入口打开新存储中的真实目标。 |
| 图片 | 手工图文编辑及素材使用新卡片存储。上传附件、当前分支生成图片可复制进卡片；读取图片使用原模型看图通路。剧情插图从本轮采用模块取得，显示与模型看图分开。 |
| 返回卡片 | 从对话返回后重新读取正式修订；不重置正在进行的编辑与输入位置。 |
| 快捷操作与存档 | 使用原对话操作注册、分支状态与存档，取消对新卡片使用线的独立文游前置要求。 |
| 文件入口 | 原附件转发弹层增加“导入为世界／角色”，通过已取得的文件流导入；不依赖遍历手机文件夹。 |
| 原生导出 | 新交换包携带正文、图片、内部角色和扩展引用；旧包转换位于边界，正文不写入旧数据库大行。对话诊断包补收录新卡片交换包。 |
| 手机页面 | 卡片详情与编辑时收起原底部导航，避免盖住按钮；返回时恢复。使用原视觉主题，保留原聊天页面。 |

## 保全规则与尚不能声称的内容

- 个别旧卡转换失败不阻塞其他卡或新建；显示未迁入项目，保留原件并可重试。
- 多版本旧角色交换包目前完整原文保留为一个模块，不擅自合并人格；原始清单、正文与媒体同时保全。
- 旧跨卡关系及版本资料作为兼容数据保留；本轮不制定尚未确认的阶段或跨世界新语义。
- 本文的代码判断不是手机实际通过记录。编译、签名、安装身份和人工点击结果分别记录，不用过去独立应用的检查冒充本次集成结果。
