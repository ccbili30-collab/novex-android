# 注入、管理及相关支线：本轮实施记录

当前故障状态只以修复工作树 `preview-icon-memory/docs/diagnostics/3.0-bug-board.md` 为准。本文记录实现与证据，不建立第二张故障表。用户授权修复与补线；不发布，不触碰稳定工作树，不删除用户数据，手机体验由用户验收。

## 已定位并修改的直接原因

| 故障 | 原因 | 本轮改动 |
|---|---|---|
| B89 大卡阻断 | 选料看摘录，选中后整块读取并强制全带；还将上一轮已带资料再次计入占用 | `BudgetedMaterials`（按预算读取资料）复用 `TextPages`（正文分页）；自动选择的内容可分段，明确下一页位置；预算按实际发送历史、系统要求、工具、状态等统一分配 |
| B89 连续管理 | 成功读取也使资料失效重算；保存后内部选料缓存反而仍可能旧 | 只在修改成功时使内容缓存失效；工具循环按更新后的剩余容量重新组织，复用选择结果；压缩按保留历史判断，避免因大卡摘录反复压缩同一份历史 |
| B90 容量不一致 | 页面推断与请求推断分叉；上游字段少；型号带日期未识别；目录数据覆盖明确容量 | 两端共用模型容量规则，解析更多明确字段及 K/M（千／百万）写法；区分输出上限；识别明确第四代日期名，明确上游容量优先；未知容量显示估算提示 |
| B91 泛化过程 | 过程行仅汇总次数；读写工具标题缺少目标；提示词可能鼓励省略解释 | 工作记录显示具体动作和目标、成功／失败状态，可展开完整结果；保留模型正常说明，要求收尾依据实际回执 |
| B06 普通叙述隐藏 | 流式处理中只要出现工具就把全部文字改标为过程 | 不推断普通文字属于隐藏过程；旧不可靠文字标记读取时也不再据此隐藏正文；工具及思考仍可折叠 |
| B92 入口重复 | 相同创建动作包装为多个入口，列表尾部再次重复 | 首页直接新建对话；作品从库开始；移除重复创建菜单和预填话术入口 |
| B93 旧分类 | 通用／设定判断不认识新卡绑定 | 首页收起这组含义重叠的筛选；保留的分类函数识别新采用关系，管理不等于采用 |

## 支线逐项核对

| 支线 | 实际连接与处理 | 检查边界 |
|---|---|---|
| 已有对话采用／管理 | 卡片更多菜单 → 选择已有对话与用途 → 原对话设置保存器 → 打开原对话；不复制卡片 | 保存器检查当前流式状态及设置版本冲突；页面实际手感待验收 |
| 人工草稿交接 | 卡片编辑入口先走共同草稿提交，成功后再选择已有对话；未改动无需重写 | 复用已有 `prepareAi`（准备人工智能编辑）；保存失败不进入下一步 |
| 只读／批准／自由 | 原对话决定是否提供工具与是否批准；卡片协调器继续检查对象、版本 | 只读大资料不静默截断后宣称全读；真正必带装不下仍明确报错，原卡保留 |
| 编辑占用、停止、重试 | 共同卡片协调器、修订和执行记录继续负责；停止与保存结果不改成虚假成功 | 复用现有编辑会话、取消与恢复检查，未新增第二套保存器 |
| 新建成果与归库 | 真实保存 → 新目标加入当前管理范围 → 原库读取共同存储 | 保留此前新库入口修复；本轮不重新实现目录 |
| 世界内部角色 | 与世界采用共同内容定位、选料及分页；管理世界可定位内部角色 | 多人物不等于复制多个主要身份；新增管理不改变主要互动对象 |
| 图片来源与归卡 | 原对话可见附件／当前分支生成图 → 图片目录 → 卡片工具 → 卡片独立资源 | 修复预算重算误删图片目录的联动；资源保存与图片观看独立 |
| 模型看图 | 卡片图片读取接原视觉路由；原生看图带图，否则使用视觉模型组 | 视觉解析失败返回失败，不能因文件已读就报告模型已看图；真实服务仍待实用验证 |
| 剧情插图 | 保留检查／选择、实际文件校验及正式正文完成后展示链 | 不因工具出现将剧情正文整体隐藏；原图生成配置未新增 |
| 快捷操作 | 保留注册 → 输入区操作 → 动作发送／查看分流 | 继续共用原对话状态和分支，未另建文游卡 |
| 状态与存档保存 | 分支状态、真实消息依据和保存回执沿用原对话实现；纳入注入总预算 | 状态不写回卡片静态设定，存档保存不冒充恢复 |
| 指定存档恢复 | 原应用已有详情与继续参考；完整的选档恢复语义仍待用户回复 | 已问恢复消息位置与状态、保留后续消息、卡片不回滚的范围。未获答前不实施这项数据改变 |
| 导入导出和图文模块 | 复用共同内容与资源存储 | 使用无害合成大文本检查本次注入修复，不将用户原包正文提交仓库 |
