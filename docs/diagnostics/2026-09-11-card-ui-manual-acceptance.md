# 卡片界面修正：用户点击验收

先看外观，再走操作。保留原卡和应用数据，安装包用于覆盖预览渠道，不能覆盖稳定渠道。无须清除数据。

## 先看三页

1. 从创作库打开一张有主图的角色卡。应先看到顶部大图，下方名称和简介，再下方文字页签及正文；不是一屏带边框的小卡片。右上角编辑为原版铅笔图标。
2. 点击编辑。应看到带边框的主图与名称／简介组，下面是横向文字页签。当前页签下为紧凑竖向模块行，有内容摘要；新增模块是一条小行。展开子模块看到层级线，不层层套框。
3. 点击一个模块。应看到名称横线与大幅正文编辑区，图片和眼睛入口在顶部；正文能输入标记文本及图片。没有底部一排重复入口。

世界与空白卡也应使用同一套页面和原版组件；空白卡不编造内容。以上任一页明显不符，就先反馈所在页面，不必继续后面的业务验收。

## 再检查状态

4. 未改内容直接返回，不出现保存询问。修改后点击眼睛，只预览草稿；回编辑仍保留输入、光标和位置。退出编辑才询问保存／不保存。
5. 新增模块后返回，仍定位到它所属页签。长按拖动：条目之间显示插入线；目标内部显示放入提示。拖动一组时子模块一起保留；也可用菜单移动。
6. 点击主图进入图片素材页，应看到大缩略图，可添加图片并设置头像、封面或插入模块。删除展示位置与删除素材不同。
7. 从世界中新建或复制内部角色，编辑后返回世界；角色自己的图、内容和位置应保留。正式保存成功后重新打开原卡查看。
