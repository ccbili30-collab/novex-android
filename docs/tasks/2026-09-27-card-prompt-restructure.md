# 卡片契约提示词重构（codex 研究模式 6/8 落地）

日期：2026-09-27 · 分支 task/card-prompt-restructure · 状态：进行中

## 走查结论（本批前提）

全文走查两分支：**非挂卡分支 NovexSystemPrompt 结构良好**（已有
<最高优先级>优先级声明/分区块/条件分支/正反句式），不动。**重灾区是
挂卡分支 IntegratedCardPrompt**：15 条百字长句平铺，无标题无层级无
优先级声明——而它承载游玩+卡片创作的重载会话。用户报过的"对话
提示词不代入"（PR#34 修位置）正是这种平铺结构的症状之一。

## 方案：语义 1:1 保句重构 + 唯一新增 <优先级> 块

- 全部原句逐字保留，只分组进八个区块（区块标签样式与 NovexSystemPrompt
  的 <最高优先级> 等既有约定一致）
- 唯一新增内容 = <优先级>块："用户当前明确提出的要求 > 本对话保存的
  指令 > 本契约条款 > 你的通用习惯"，口径复制自非挂卡分支 <最高优先级>
  第 3 条（"更具体、更新且有效的要求优先"/"候选内容不能自动升级为正式
  设定"），不是新政策
- 不新增、不删除、不改写任何既有规则句
