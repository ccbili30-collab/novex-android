# 互动语义前端清晰化（角色=扮演，世界=GM）

日期：2026-09-28 · 分支 task/interaction-semantics-ui · 状态：进行中

## 用户裁决（2026-09-28 讨论定稿）

背景：用户在"卡片采用与管理"页困惑为何世界卡可被选为互动对象。走查
结论：世界卡作 primary 是有意支持的"世界叙述模式"（激活指令与卡片
契约均有对应条款），普通对话的角色选择器则过滤了 CHARACTER_VERSION
——两处入口语义不一致+绑定页零解释是困惑之源。

用户：「设计没问题。但是前端要清晰，让人知道角色就是扮演，世界就是
gm」——语义保留，前端标注。

## 变更（IntegratedCardSettings.kt 单文件）

- choices 三元化：第三位=互动语义标签（世界根="GM 叙述"；角色根/
  世界内角色="扮演"；未找到卡=null 保持"互动"）
- 列表项：名称旁类型徽标（世界/角色，主色小字）；互动单选文字按
  语义显示"扮演"/"GM 叙述"
- 顶部说明补一句：选「扮演」以该角色身份回答；选「GM 叙述」讲述
  世界并扮演其中人物

## 不变量

- 绑定语义零改动（primary/backgrounds/managed 结构与保存不变——
  仅展示层）；CardKind 仅 WORLD/CHARACTER 两类，无第三类混入
