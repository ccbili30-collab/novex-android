# 对话仓库批量资料入库与按需读取

## 用户确认的范围

每段对话可以持久保存大量资料，模型按任务查找、读取。入库不发送聊天消息，不启动模型，不把全部正文加入提示词。保持现有视觉风格；在现有对话空间扩展入口，不再另造一套仓库。

## 实现

- 对话设置 → 内容与工具 → 对话空间 → 打开对话仓库 → 导入资料。
- 文件多选和文件夹导入；文件夹保留层级，列表可逐层浏览、按名称查找。
- 一次按文件逐个保存，沿用单文件 64 MiB（约 67 MB）的现有存储上限；没有每批 50 个文件的聊天附件限制。总量仍受设备空间和处理能力限制。
- 使用原有文件存储、成果登记和文档解析器。成功入库立即显示；原件与解析阅读文本关联，解析副本不作为重复文件显示。
- 相同路径和内容复用，内容不同另存；原件不被覆盖。空文件可以导入，模型生成空成果的原有限制保留。
- 导入状态独立于页面；可离开、停止、重新选择继续。进程中断后保留已保存文件，并提示重新选择。解析失败也保留原件，并给出提示。
- 资料属于对话公共根目录，对本对话分支可见；模型生成的笔记、草稿与成果继续沿用既有分支隔离。
- 原件进入回收站后，原件与关联解析文本一起停止供仓库工具读取。显式重新导入可恢复；普通目录核对不会重新登记已删除的导入文件。
- 仓库查看支持名称、文件夹筛选与分页；正文关键词查找每批至多返回 25 个命中文件，扫描按时间和字节预算分批，每文件返回首个命中片段。读取支持从命中位置开始，并继续分段读取。
- 搜索不计为通读；解析文本的阅读记录不能冒充原件所有图片、排版与内容已读。资料变化后旧翻页位置失效，要求重新查询。
- 对话仍沿用已有只读、批准、自由三档权限；只读模式不因入库而获得工具。模型提示词第六版候选不替换正式版。

## 代码边界

- 资料保存、目录查找与访问隔离分别放在核心模块的新文件中。
- 安卓系统文件选择和后台导入由独立导入服务负责，不写进聊天执行大文件。
- 前端沿用创作文件页面；新增导入操作组件，保留原有预览、收藏、导出和回收站。
- 当前对话查询直接按对话筛选；工具只读取可用文件路径，不加载全库正文和所有修订。
