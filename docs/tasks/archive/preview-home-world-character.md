# Novex 预览线：首页、世界与角色界面基线

本文记录 2026-09-02 已经确认的产品结论，作为后续实现和验收依据。它描述界面与交互，不替代 `CONTEXT.md` 中的领域定义。

## 范围

- 本阶段实现会话首页、世界库、角色库三个顶层空间及其清晰可达的详情层级。
- 保留“帮我创作”入口框架，但暂不实现人工智能管理、生成地图或生成角色。
- 暂不实现多角色共同对话；一段世界对话只选择一个角色本体或分身。
- 只开发预览线，不修改正式分支，不在本检查点发布安装包。

## 信息架构

三个顶层空间分别承担不同任务：

1. 会话：用于快速继续最近对话，以及新建通用对话。
2. 世界：用于浏览和管理世界，再进入具体世界详情。
3. 角色：用于浏览角色根对象，再进入本体与分身详情。

具体世界、具体角色、模块编辑器和对话都属于详情页。详情页隐藏顶层导航，通过系统返回或页面返回键回到原顶层空间。

会话首页只保留三种内容视图：

- 最近：聚合各个世界内的最近对话，并显示具体世界与角色版本上下文。
- 通用：只显示没有绑定世界的对话。
- 创作：当前显示真实的“即将开放”占位入口，为未来统一创作中心预留位置。

首页不再显示“我的世界”概览卡；世界已有独立顶层入口。顶部加号用于创建或导入内容，底部“新建对话”用于开始对话，两者语义不能重复。

## 顶层导航

底部导航默认收起：当前空间显示为带名称的胶囊，其余空间显示为圆点。

- 点击任意圆点：展开全部带名称的按钮并切换到对应空间。
- 展开后点击其他空间：完成切换并保持展开。
- 点击导航外部：收起。
- 按住导航并左右拖动：连续预览目标，松手切换。
- 在三个顶层根页面的空白内容区水平滑动：切换相邻空间。
- 详情页、编辑页、地图、图片横向内容和系统边缘返回区域不响应顶层切换手势。
- 竖向滚动优先；只有明显的水平意图才触发切换。

## 世界页面

世界使用偏横向、画廊式的视觉语言，不做成狭窄的设置清单。

- 基础视觉：封面、标志、全屏背景、名称、标签。
- 只有世界观概述默认存在。
- 时间线、时代事件、地图、地区、势力、种族和自定义模块由用户主动添加。
- 模块卡应预览真实内容，例如地图缩略图、事件摘要、势力标志和图片，而不是只有图标、文字和箭头。
- 角色版本板块使用全宽布局，可从角色库加入本体或分身。
- 玩家身份不属于世界；开始世界对话时再选择。
- “帮我创作”保留在右上角，当前只提供诚实占位说明。
- 缺少角色版本时，开始对话入口应引导添加，而不是形成无响应按钮。

## 角色页面

角色使用偏纵向、人物档案式的视觉语言。本体和分身都是同一角色下的角色版本。

- 角色库首先展示角色根对象；本体／分身关系以“本体 · N 个分身”的轻量入口呈现，不长期占据首屏主视觉。
- 从角色库进入时默认展示本体；从世界进入时直接展示该世界关联的具体角色版本。
- 点击轻量版本入口后，以底部面板选择本体或分身；切换后页面内容全部属于当前角色版本。
- 创建角色时只要求名称，并自动创建本体。
- 头像、主页背景、标签、性别、年龄、种族、职业、简介均允许留空。
- 年龄、性别、种族和职业使用可自由填写的文本，不锁死为数值或固定选项。
- 不显示“完成度”分数，也不把玩家身份放在角色页。
- 世界关联属于具体角色版本，使用全宽区域，并在编辑共享版本前显示影响的世界。
- 自定义属性、原创角色关系及所有角色模块默认折叠或按需添加。
- 角色模块包括：多形态语录、世界经历、属性面板、随身装备、天赋技能、外貌性格、兴趣爱好和自定义模块。
- 图片区域表达为可选的外观素材或参考图，不强制上传代表图片。

## 展示、编辑与预览

- 世界和角色都采用一致的“展示页 → 编辑页 → 草稿预览”层级，不能让展示页直接退化为长表单。
- “帮我创作”固定在展示页右上角，暂不实现人工智能管理能力。
- 编辑页中的内容模块可以点击展开编辑；允许多个模块同时展开，重新进入页面时默认折叠。
- 模块可以通过拖动手柄上下排序，并提供显式上移、下移操作作为触控与无障碍替代。
- 预览读取尚未保存的当前草稿，使用与正式展示页完全相同的模块渲染器。
- 内置模块每种只允许添加一个，但模块内部可以包含多个条目；自定义模块可以添加多个。

## 新视觉组件

- 首页、世界和角色页面不沿用 Material 3 的默认卡片、按钮和底部导航外观。
- 图标以 Phosphor Icons 为主要来源，只收录实际使用的 SVG 文件并固定版本；缺失的领域图标按同一 24×24 网格和描边规则补画。
- 页面使用 Novex 自有的顶部栏、媒体卡片、模块预览、可排序模块和聚合圆点导航组件。
- 保留 Android 系统返回、安全区、触摸目标、文字缩放和无障碍语义，不通过自定义外观破坏平台行为。

## 默认视觉指纹

世界和角色在没有上传图片时显示淡色、稳定且可区分的系统视觉指纹：

- 同一个对象每次打开保持一致，不依赖网络或人工智能服务。
- 世界使用抽象地貌、云层、轨道或天体等横向构图。
- 角色使用抽象轮廓、纹理和色块，不虚构具体人脸。
- 视觉指纹不是媒体资源，不写入图片资产表，也不参与共享图片引用计数。
- 用户上传封面、背景或头像后，上传资源覆盖对应默认视觉。

## 稀疏与密集状态

- 内容很少时，页面保留呼吸感和明确的添加入口，不渲染成排满“尚未填写”的空表格。
- 内容很多时，列表只展示缩略图和短摘要，正文留在独立详情页；模块、角色版本和对话分区可折叠或限制首屏数量。
- 所有页面优先保证手机触控目标、软键盘避让、安全区和系统返回手势可用。

## 验收要点

- 冷启动进入会话首页，后台恢复保留原页面。
- 三个顶层空间可点击到达，也可通过明确的水平手势切换。
- 从世界或角色进入详情再返回时，回到原空间并恢复页面状态。
- 最近、通用和创作的归类与空状态真实准确。
- 世界与角色没有图片时显示稳定的默认视觉，有上传资源时正确覆盖。
- QQ 群反馈入口保持在设置页最上方。
- 顶层切换不触发工具、模型请求或其他外部副作用。
