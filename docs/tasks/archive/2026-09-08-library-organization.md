# 创作库归类与对话设置整理

状态：本轮实现及验收完成，尚未发布。基线为 `ca8fa85`，保留前轮对话基础修复；修改位于当前工作区。

## 已完成的用户行为

- “全部作品”作为紧凑的创作库筛选入口。用户可建立多个并列创作库和嵌套文件夹，收录、移动或移出已有卡片及文件；同一对象可被多个库收录，原件保持唯一。
- 世界、角色、文游主页仍展示对应类型。创作库选中某个库后，展示其中的文件夹、卡片与文件；可打开实际内容。
- 引用选择从用户可见仓库逐级浏览，支持跨来源勾选。私有空白占位卡、内部编号和未进入可见仓库的记录不混入选择列表。当前没有内容的世界库、角色库不占用选择入口。
- 对话设置整理成四组：身份与回答、使用的设定、内容与工具、其他设置。原功能进入子页；内部返回保留草稿并收起键盘，真正离开编辑时仍保留原有未保存处理。
- 文件列表显示可读名称，去掉系统附加的长编号，保留真实扩展名；原文件名、存储位置、内容与导出不改。新建内容的产品教学轻度引导简短命名，尊重用户指定标题。
- 保留原有配色、圆角、封面、渲染与预览；调整标题、说明比例和行数，去掉重复的新建／导入大行入口及冗余说明。
- 共用底部弹窗的外层描边画在面板位移之外，产生遮罩中的矩形白线。已移除该额外描边，保留面板圆角和内容分隔线；两种高度的真实截图均确认白线消失。

## 数据与权限边界

复用原作品分组编号及收录表，数据库从 31 升至 32，为旧分组增加带校验的文件夹组织数据。成员收录与文件夹位置在同一事务保存；无效目标整体回滚，位置冲突拒绝覆盖。删除非空文件夹须先移出内容；移除创作库保留卡片、文件原件及其他库的收录。

库的收录和筛选不修改回答身份、背景采用或工具权限。“选择这里的全部内容”只选当前内容；一段对话仍只有一个活动文游，管理区可以包含多张文游卡。私有空卡仍可供人工智能内部创作，继续创建多张卡的能力保持。第六版提示词候选未替换正式版本。

文件保存、移入回收站或恢复会通知当前页面刷新，避免实际已保存而列表未更新。选择器与页面复用同一可见目录；每张卡和文件使用稳定编号定位，不按重名重新绑定。

## 用户入口

1. 卡类主页或创作库顶部“全部作品” → 新建／管理创作库 → 新建文件夹、加入内容。
2. 对话设置 → 使用的设定 → 背景资料／当前文游。
3. 对话设置 → 内容与工具 → 对话空间／可管理内容／工具权限。
4. 已有内容的卡类主页顶部“新建”菜单保留新建与导入。
