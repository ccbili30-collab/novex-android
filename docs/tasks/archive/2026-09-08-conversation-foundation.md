# 对话与卡片地基修复执行记录

状态：本轮软件底层修复与交互验收完成，尚未提交、合并或发布。模型表达与语义忠实性仍有下列明确限制，不宣称全部解决。基线为预览版 36 对应的 `e5c29e6`，实际修改位于 `feat/conversation-foundation`（对话地基任务分支）。本记录覆盖此前方案中已经被用户纠正的归库时机与批准方式；旧版本记录保留为历史，不作为当前行为要求。

## 本轮必须保持的产品关系

- 三张私有空卡和一个内容空间是新对话的起点，不限制创建数量。成功保存实际内容立即在对应仓库可见；仓库和对话打开的是同一对象，不再要求返回列表才能入库。
- 身份、背景、管理与权限各自独立。多个世界和人物可作为背景；多张文游可管理，但只有一个活动文游。保存和修改不会自行启动游玩或刷新已经采用的快照。
- 只读不发工具定义；批准对每次具体操作弹窗，一次勾选完成批准；自由调用不追加文字授权。明确只读的外部对象仍受保护。
- 卡片复用既有模块、编辑器和渲染。排序修改顺序，索引记录用途，修改已有模块沿用编号。文件与成果保留来源；删除对话保留独立保存作品。
- 正式回答、执行过程、批准与成果入口分别呈现。原始工具输入、结果、思考及消息仍保存、可导出，不能为了简洁删掉证据。
- 第六版提示词保持未验收候选，不发送给正式模型。用户自定义提示词与图片提示词不被覆盖。

## 已接入实际调用的职责边界

| 职责 | 实际实现与调用 | 行为证据 |
| --- | --- | --- |
| 保存与归库 | `NovexWorkspace`（内容工作空间）、`NovexConversationDrafts`（对话草稿）、`NovexLibraryChanges`（库变更通知） | 同一事务后立即列出作品，旧隐藏成果恢复，重试不重复新增，空占位仍隐藏 |
| 卡片操作 | `NovexContentToolExecutor`（内容执行器）、`NovexCardFileService`（卡片文件服务） | 主对话分发已调用新执行器；卡片与管理配置一起提交，失败一起回滚 |
| 批准与执行 | `NovexToolExecution`（统一操作执行）、持久操作记录 | 普通工具、卡片、记忆和整理使用同一权限入口；旧待办恢复、拒绝与失效终结有真实记录 |
| 对话恢复与删除 | `NovexPendingToolTurn`（待完成工具回合）、`NovexConversationDeletion`（删除生命周期）及运行域封闭 | 先核对旧回执再继续，结果先保存；删除等待运行停止，阻止同一编号重新启动，失败可重新打开 |
| 长资料 | `NovexLearningExecutionPlans`（持久整理计划）、`NovexLearningPreflightBuilder`（整理预检）、`NovexLearningRunCompletion`（完成衔接） | 范围、修订、模型和累计预算保持一致；模型调用等待整理结束或暂停后继续原任务；手动后台入口保留 |
| 流式回合状态 | `AssistantStreamTurn`（助手流式回合） | 主循环实际使用；文字、思考、工具片段、签名和结束状态由同一对象维护，重试统一清理，宿主只接展示快照 |
| 请求重试 | `NovexModelStreamRecovery`（模型请求恢复） | 主流式循环已使用；有界重试、连接切换、取消、失败片段清理统一，连接编号保留，不重跑已完成工具 |
| 消息与展示 | `AssistantTurnPersistence`（助手回合保存）、执行过程与批准组件 | 执行文字由宿主标识，原始数据保留；正式答复用于复制和朗读；成果按钮显示卡名 |
| 模型资料目录 | `NovexManagementModelView`（模型目录视图） | 先给卡片与模块目录，指定模块才给正文，高级格式按需查看；完整页面与导出快照不变 |

这些模块已经替换真实调用，不是另一套演示实现。对话状态文件仍保留消息分支、语音及旧功能协调逻辑；本轮从主文件净移出约一千行，尚不能声称已经成为薄界面适配层。后续迁移必须继续围绕状态所有权和执行顺序，不能仅为降低行数搬成依赖主对象的扩展函数。

## 已实现的前端入口

- 对话设置使用只读、批准、自由三档；主要回答身份为诺瓦、自定义或具体角色，旧主持预设按自定义保留。
- 对话内的管理内容合并显示来源对象，卡片与资料的用途清楚区分。列表筛选只影响当前选择页。
- 世界、角色与文游详情复用内容／关系与使用／管理分区和已有正文渲染。世界主按钮带背景直接开始诺瓦对话，选择角色是显式操作，不强迫先建玩家身份。
- 对话菜单接真实删除与完整对话包导出；资料、整理进度和存档收拢为次级入口。返回列表不等于删除或结束文游。
- 执行过程默认折叠；批准、失败和可打开成果保持可达。旧输入框上方的重复浮动工具条及原始结果缩略图已移除，记录统一从折叠区进入。窄屏分区标题与说明改为上下排列，避免说明把标题挤成竖排。
