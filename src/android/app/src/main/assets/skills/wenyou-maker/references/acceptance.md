# 验收清单与质量件（→ 16 模块 + 交付前自检用）

## 一、验收清单（二值判定，全过才交付）

- [ ] 七插槽决策表完成且理由成立
- [ ] 事件池 ≥100 条，分 5-8 类，每类有权重/触发/冷却
- [ ] 人物或物种卡 ≥15 张，含高危加粗与时间线限定
- [ ] 目标卡 ≥20 张，三档分层，≥5 张连环
- [ ] 成长判定公式 + 对抗判定公式 + 各一算例
- [ ] 核心资源 3-5 项，各有归零后果
- [ ] 死线机制存在且面板可见（面板死线行模板已写）
- [ ] 02·每轮注入 总长 ≤8000 字符（实测，非估算）
- [ ] 常驻模块（01-07+10-11）合计 ≤15000 tokens（估算并记录）
- [ ] 黑名单 ≥20 条，全部题材语境化，全部带"改做"
- [ ] 序章剧本按出身差异化；开局问卷分步
- [ ] 黄金回合样本齐全（见下）
- [ ] 与宪法零冲突自查（重点：有没有引入"面板可因剧情修改"类条款）
- [ ] 抽查对账 5 个 ID 三方一致
- [ ] 不确定的原著内容全部标注【推演】

## 二、红线黑名单写法（→ 10 模块，always）

≥20 条，**每条必须用本题材的具体语境写**，格式：

```
编号. **错误行为（题材具体场景）** → 违反哪条法则/模块。改做：正确行为的具体替代。
```

好例（雨世界风格）：
`1. **让蛞蝓猫说人话或成段内心独白** → 违反文风锁。改写：用动作、竖毛、叫声、气味标记表达。`

坏例（禁止这样写）：
`1. 不要让角色做不符合设定的事。`（无语境、无替代行为，等于没写）

黑名单的内容来源（按优先级）：
1. 该题材最著名的"AI 会写错"点（原著主角设定串台、时间线错乱、著名机制写错）
2. 世界法则的高频违反方式（每条法则配 1-2 条黑名单）
3. 通用反例：让 NPC 未ト先知 / 替玩家决定 / 无光环境正常行动 / 复活无代价 / Boss 提前登场

## 三、黄金回合样本（→ 16 模块，manual）

本题材的**完整一轮范本**，必须包含全链路：
```
【玩家】（一句有风险的行动声明）

<外部状态> 第 N 轮 + <账本>上一轮快照 </外部状态>
<骰值>1d100=63; 1d100=8</骰值>

【GM】
①承接……②情境叙事350字（判定过程在叙事前公示：63+4-12=55 vs 50 → 成功）
③✦ 面板（含死线行，变动标▲▼）
④1-3 选项各附风险/收益 ⑤0.🎭自由行动 ⑥S.🖥️系统沟通
⑦⏳时间流逝 ｜ 🌍世界暗流一行 ｜ <账本>完整块（≤15行）
```

样本的作用是给运行期 GM few-shot 锚点——它比十条抽象规则更能锁住输出格式。

## 四、冷启动剧本（并入 08·开局流程 末尾）

给前 3 轮一个节奏锚，防开局失真：
- 第 1 轮：命名锚定 + 世界入场（低风险，教学判定）
- 第 2 轮：首次真实判定（用掉一枚外部骰，公示公式）
- 第 3 轮：死线首演（倒计时第一次显形，压力出现但可应对）
- 三轮禁忌：不致死、不揭核心真相层、不出现最高危势力/物种
