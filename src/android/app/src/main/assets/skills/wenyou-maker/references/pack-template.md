# 题材包模板（填 03-09 模块用）

原则：**能表格化的不写散文；能给出公式的不给形容词；每条规则带一个例子。**

## 〇、七插槽决策表（写进 00·启动说明 顶部，先决策再填表）

| 插槽 | 选项 | 本世界选择 | 一句话理由 |
|---|---|---|---|
| 成长引擎 | 单塔力量线 / 多线人生线 / 资源-科技线 / 生态位线 | | |
| 对抗系统 | 战斗公式 / 生态链捕食判定 / 社交博弈 / 生存压力判定 | | |
| 时间结构 | 年 / 月 / 日 / 时段 / 阶段单元（周期/季节/副本） | | |
| 原典锚定 | 锁死 / 半锁（软硬锚点）/ 全开放 | | |
| 死亡观 | 转世多周目 / 循环重生（有代价）/ 真实死亡 / 继承再启 | | |
| 世界结构 | 单一世界+轨道后台 / 多区域+条件解锁 | | |
| 文风锁 | 一句话定义 + 禁词表 | | |

## 1. 世界观与法则（→ 03 模块，always）
- 世界一句话设定 + 3-5 层核心真相（由浅入深，标注每层揭晓条件）
- 世界法则 3-6 条（本世界的"物理"，每条一句+一例）

## 2. 力量与成长体系（→ 04 模块，always）
- 阶段表：`阶段 | 称号/状态 | 解锁能力 | 成长代价 | 代表参照`（≥6 行）
- 成长判定公式（显式）：`成功/进展判定 = 基础率 + 属性×系数 + 资源加成 − 难度修正`，附一个完整算例
- 属性表：4-6 维（每维一句话定义 + 初始值范围 + 上下限）
- 对抗判定公式 + 一算例 + 碾压规则（差距多大时直接判定）

## 3. 资源与经济（→ 05 模块，always）
- 核心资源 3-5 项：上限、消耗速率/触发、**归零后果**（归零必须有死亡级后果或事件）
- 价值锚点表 ≥5 行（"1 份干粮 ≈ 半天安全"式锚定）

## 4. 时间与死线（→ 06 模块，always）
- 时间推进规则（一轮=多久；什么情况压缩为岁月如流）
- **死线机制**（强烈建议）：面板可见的倒计时（雨季/冬天/围攻/病发），及到期分支后果
- 面板死线行模板（每轮必出）

## 5. 势力与生态（→ 07 模块，always）
- `势力/物种A × B` 交互矩阵 ≥5×5（态度+行为倾向），或生态链位次表
- 每势力/物种一段：利益、地盘、与玩家的可能关系

## 6. 开局（→ 08 模块，manual）
- 难度 4-5 档表（含一档作弊模式：二次确认+成就标记"作弊获得"）
- 模式 A/B/C（A 原著角色 / B 自创（出身表 ≥6 类，一强一弱）/ C 穿越者+系统（预设 ≥6 种））
- 开局问卷：**分步引导，每步 ≤6 个选项，禁止一次铺开**
- 序章第一幕剧本：按出身差异化，各 150-300 字

## 7. 结局（→ 09 模块，manual）
- 结局库 ≥10 种：`结局名 | 达成条件 | 评语风格`
- 结算评价 S-D 维度表 + 死亡处理（按死亡观插槽）

## 质量线
1. 一切数值有公式，一切公式有算例；
2. 表格行内没有形容词堆叠（"非常强大"违规，"战力系数×3"合格）；
3. 每张表至少一行示例带"反例"（玩家最常误解的点）；
4. 与引擎宪法零冲突。
