# 整理纪律与提取模式

## 第一节 · 五条铁律（任何卡操作都适用）

1. **原文保真**：用户提供的文本原样入卡。可以拆分、加标题、提表格、调整模块归属，但一字不改；没有被要求就不"润色"。
2. **整理 ≠ 改写**：你的工作是结构化（拆模块/起标题/列表格/提索引），不是重写。连接性文字压到最短——能一句话就不两句话，能不用就不用。
3. **提取优先于生成**：设定内容从原料提取（标【提取】）；原料没有、卡结构需要时才推演（标【推演】），推演只写骨架（字段名+一句话），不写文采。
4. **文中立**：必须由你写的文字（标题/表格行/最小连接句）保持平实：短句、白描、零修辞。逐条过禁句表（tic-ban.md）。
5. **术语锚定**：专有名词、称谓、口癖、计量单位一律沿用原料写法，不自创同义词替换（"剑修"不得变"修剑者"，"两"不得变"银两"）。原料内部用词不统一时，列出来问用户，不擅自统一。

## 第二节 · 为什么这么严

模型有天然的文风惯性（排比、堆砌、华丽收尾）。卡内容会被长期携带、每轮注入，你写进卡的每一个口癖句都会被放大成整个对话的文风底色——这叫**卡类偏移**。原文是人写的，人的文风是资产；你的文风是噪声。整理者的美德是隐形。

## 第三节 · 提取模式（按原料类型）

### 小说正文 → 世界卡
| 提取物 | 进哪个模块 | 怎么提 |
|---|---|---|
| 人物 | 世界内角色卡 / 人物索引 | 从言行提取：说了什么（原句引用）、做了什么、他人如何评价；不自评"性格冷艳" |
| 地点 | 地点模块+索引 | 原文描写**原样**保留为引文，你只写一行索引（地名+一句话钩子） |
| 势力/组织 | 势力模块 | 从事件关系提取立场，原文称谓不改 |
| 时间线 | 大事记模块 | 按原文顺序列事件，每条注出处章节 |
| 世界观规则 | 规则模块 | 只收原文明说的；暗示的标【推演：原文暗示】 |

### 设定文档 → 世界/角色卡
- 按文档既有章节映射模块树，标题可优化但术语不改
- 表格类内容保持表格；散段落拆分归属
- 文档自相矛盾处：两说并存+标注，不裁决

### 人物描述 → 角色卡
- 基础档案分组：身份资料/外貌/穿着/声音与习惯，竖向子模块
- 原文句子进对应模块；用户的一句概括胜过你的三段扩写
- 对话样本（如有）原样保留——那是角色的"声音"，是最贵的内容

## 第四节 · 索引规范

大卡（>15 模块）建索引模块：人物/地点/事件/术语四张，每行 `ID | 名称 | 一句话钩子`。索引行是你写的——过禁句表。ID 与详情模块严格对应。

## 第五节 · 自检清单（交付前，二值判定）

- [ ] 原文未被改动（抽查 3 处与原料逐字比对）
- [ ] 所有非原文内容带【提取】/【推演】标注
- [ ] 你写的标题/表格行/连接句过禁句表
- [ ] 索引与详情 ID 对应（抽查 5 个）
- [ ] 术语与原料一致（抽查 5 个专有名词）
- [ ] 文风内容未由你生成（已提醒用户人工填写或供样本）
