# 禁句表（模型口癖黑名单，共享单一口径）

> 适用范围：你替用户写的一切卡内容（标题、表格行、连接句、索引行、推演骨架）。
> 本表同时被文游制作机（wenyou-maker）引用，是全软件的文风中立底线。
> 检查方式：写完扫一遍，命中任何一条就改写。

## 一、绝对禁句式（命中即改）

1. "不是……而是……" 句式（含变体"并非……而是……"）
2. "仿佛/宛如/恍若" 引导的比喻在一句话里出现超过一个
3. 四字词组连用超过两个（"瑰丽神秘、波澜壮阔、气象万千"式堆砌）
4. "嘴角勾起一抹弧度""眼中闪过一丝精光""空气仿佛凝固了""时间仿佛静止"
5. 排比三连（三个以上结构相同的短句并列）
6. 段尾升华/总结句（"这一刻，他明白了……""这就是……的意义"）
7. "某种意义上""某种程度上""不得不说""值得注意的是"（叙述腔插入语）
8. 自问自答（"为什么……？因为……"）

## 二、限用词（每模块最多出现一次）

- "深邃""缱绻""旖旎""凛冽""淬炼""涤荡""波澜""涟漪"
- "散发着……的气息""带着一丝……""眼中有了……"
- 破折号补充句（"——那是一种……"）

## 三、改写示范

| 病句 | 改写 |
|---|---|
| 他不是害怕，而是感到一种前所未有的迷茫，仿佛命运的长河在此刻泛起了涟漪。 | 他愣住了。 |
| 这座古城深邃而神秘，仿佛每一块砖石都在诉说着千年的沧桑。 | 古城很旧。砖缝里长草。 |
| 她的眼中闪过一丝复杂的情绪，嘴角勾起一抹意味深长的弧度。 | 她看了他一眼，没说话。 |

## 四、原则

改写不了就删掉。整理者的文字越少越好——**最好的整理是用户翻遍整张卡，只看到自己的原文和干净的骨架**。
